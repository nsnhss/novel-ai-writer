> 版本：v1.0.0

## 1. 安装与首次启动

### 1.1 下载安装

从 [GitHub Releases](https://github.com/nsnhss/novel-ai-writer/releases) 下载对应平台的安装包：

| 平台 | 安装包 | 说明 |
|---|---|---|
| Windows | `.msi` 或 `-setup.exe`（NSIS） | NSIS 安装器支持简体中文 |
| macOS | `.dmg`（分 Apple 芯片 `aarch64` 与 Intel `x64`） | 要求 macOS 11.0 及以上 |
| Linux | `.AppImage` / `.deb` / `.rpm` | — |

> **macOS 用户请注意**：当前版本未使用 Apple 开发者证书签名。首次打开时系统可能提示"无法验证开发者"，请在「访达」中**右键点击应用 → 打开**，在弹窗中再次点击「打开」即可。之后可正常双击启动。

### 1.2 首次启动

- 应用窗口标题为「AI 小说写作」。
- 若你还没有配置任何模型，应用会**自动创建一个默认模型：Ollama 本地的 `qwen2.5`**（端点 `http://localhost:11434`）。
- 如果你本机没有安装 Ollama，这个默认模型无法使用，请按下节说明配置你可用的模型。

## 2. 配置 AI 模型

打开右上角齿轮图标进入**设置 → 模型 / API**。

### 2.1 支持的提供商

应用支持两类提供商（**没有** Claude / Gemini 专用入口，但可通过 OpenAI 兼容端点间接接入）：

| 提供商 | 说明 | 默认端点 | 默认模型名 |
|---|---|---|---|
| **Ollama（本地）** | 本机运行，无需 API Key，离线可用 | `http://localhost:11434` | `qwen2.5` |
| **OpenAI 兼容 API** | DeepSeek、OpenAI 及其他兼容服务 | `https://api.deepseek.com` | `deepseek-v4-flash` |

### 2.2 模型管理

在「模型 / API」设置页你可以：

- **添加 / 编辑 / 删除模型**；
- **设为默认**、在底部状态栏或 AI 面板**切换当前模型**；
- **测试连接**：保存前验证端点与 Key 是否可用；
- **单独保存 API Key**：Key 存储在**系统凭据管理器**中，不会写入数据库或明文文件；
- 使用内置「**推荐模型**」一键配置常用模型。

每个模型可独立调整生成参数默认值（均可在 AI 面板临时覆盖）：

| 参数 | 范围 | 默认值 |
|---|---|---|
| 温度 | 0 – 2 | 0.7 |
| Top P | 0 – 1 | 0.9 |
| Top K | 0 – 100 | 0 |
| 重复惩罚 | 0.5 – 2 | 1.0 |
| 频率惩罚 | -2 – 2 | 0.0 |
| 最大 Token | 100 – 16000 | 2000 |

> 应用内**没有代理（proxy）设置项**；如需代理请使用系统级代理。

### 2.3 嵌入模型（RAG 检索用）

「素材库」的语义搜索依赖嵌入模型，在**设置 → 嵌入**中配置：

- 提供商同样为 Ollama / OpenAI 兼容二选一；
- Ollama 默认 `bge-m3`（1024 维）；OpenAI 兼容默认端点 `https://api.deepseek.com`、模型 `deepseek-embedding`；
- 可设置端点、模型名、API Key、向量维度，支持「测试连接」；
- **修改嵌入配置后需重启应用生效**。

## 3. 界面导览

```
┌──────────────────────── 顶栏 ────────────────────────┐
│ 书籍切换 ▾ / 卷·章面包屑      👁隐私  🌓主题  ◀ ▶  ⚙设置 │
├──────────┬──────────────────────────┬────────────────┤
│  左侧栏   │      Markdown 编辑器       │    右侧栏       │
│ 作品管理  │                          │ 7 个功能面板    │
│ 卷/章树  │                          │ (Tab 切换)     │
│ 章节大纲  │                          │                │
├──────────┴───────── 状态栏 ──────────┴────────────────┤
│ 当前模型 · Ollama状态 · 耗时/tokens · 字数 · 保存状态     │
└────────────────────────────────────────────────────────┘
```

### 顶栏

- 左侧：书籍切换下拉 + 当前卷/章面包屑。
- 右侧按钮：**隐私脱敏开关**（眼睛图标）、**主题切换**（浅色/深色）、**收起/展开左栏**、**收起/展开右栏**、**设置**（齿轮）。

### 左侧栏（作品 + 章节树）

- 宽度默认 260px，可拖拽调整（180–400px）。
- 顶部作品下拉：切换作品、**新建作品**、重命名本书、**导出本书**（Markdown / TXT）、删除本书。
- **卷 → 章**两级树：新建卷/章、双击或右键行内重命名、删除（二次确认）、上移/下移、拖拽排序（卷内章节），每章显示字数。
- 当前章节中的 Markdown 标题（`#` ~ `######`）会自动解析为**大纲节点**，点击即可跳转光标。

### 中间编辑器

- CodeMirror Markdown 编辑器，支持软换行、撤销/重做、搜索。
- 底部**状态栏**显示：当前模型名、本地 Ollama 可用状态（每 30 秒自动检测）、上次生成耗时与 tokens/s、生成错误提示、**实时字数**（含中文标点统计）、保存状态（「保存中… / 未保存 / 已保存 HH:mm」）。

### 右侧栏（7 个面板）

宽度默认 340px，可拖拽调整（240–500px）。7 个 Tab 全部 keep-alive，切换不丢状态：

| 面板 | 功能 |
|---|---|
| **AI** | 续写、多分支、改写、大纲、摘要、历史、参数调节（详见第 5 节） |
| **素材** | 素材库管理：搜索、导入导出、标签、入库整理（详见第 6 节） |
| **模板** | 场景模板：名称、分类、Prompt 模板、节拍表 |
| **角色** | 角色卡：姓名、别名、描述、背景、性格、关系、自定义字段 |
| **场景** | 场景卡：场景名、描述、地点、时间、氛围 |
| **锚点** | 关键设定锚点（≤50 字 + 分类），供一致性检查 |
| **风格** | 风格画像提取与管理（详见第 8 节） |

## 4. 基本写作流程

### 4.1 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+S` | 立即保存当前章节 |
| `Ctrl+Enter` | AI 续写（从光标处流式生成） |
| `Ctrl+Shift+Enter` | AI 改写（需先选中文字） |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+F` | 编辑器内搜索 |
| `Esc` | 依次关闭：设置页 → 右侧栏 |

> macOS 上 `Cmd` 等同 `Ctrl`。所有快捷键均可在**设置 → 快捷键**中自定义。

### 4.2 自动保存

应用采用多层自动保存机制，**基本不可能丢稿**：

- 停止输入 **5 秒后**自动保存；
- 编辑器**失焦立即保存**；
- **切换章节前**强制保存未落盘内容；
- 光标位置按章节记忆，重启后自动恢复。

### 4.3 字数统计

实时统计（中文标点与全角符号也计入），显示在底部状态栏和左侧章节树中。

## 5. AI 功能详解

右侧栏「AI」面板是核心工作区。

### 5.1 续写（`Ctrl+Enter`）

- 从光标处**流式续写**，生成中可随时中断；生成期间编辑器只读。
- 生成结束后文本**高亮待确认**，你可以：
  - **接受**：保留文本；
  - **接受并入库**：保留文本，同时把生成内容存入素材库（可选内容级别：通用 / 灵感 / 文风参考 / 大纲 / 人物卡 / 场景卡）；
  - **拒绝**（二次确认）：丢弃；
  - **评分 1–5 星**：评分会用于素材质量管理与 Prompt 自动调优建议；
  - **局部编辑 / 再次生成 / 复制**（编辑器内生成工具条）。

### 5.2 多分支续写

一键同时生成 **3 个方向**的续写：

- **A**：偏动作 / 冲突
- **B**：偏心理 / 情绪
- **C**：偏对话 / 互动

可单独重新生成某一分支，对比后**采用其一**。

### 5.3 改写（`Ctrl+Shift+Enter`）

1. 在编辑器中**选中要改写的文字**；
2. 按快捷键，输入改写要求（如"改得更含蓄一些"）；
3. 弹出**改写对比（Diff）对话框**，逐段对照原文与改写；
4. 选择接受或放弃（有未接受的改写时关闭会二次确认）。

### 5.4 生成大纲

输入 **100–500 字**的故事梗概，AI 生成章节大纲并插入光标处。

### 5.5 上下文预览与 Token 预算

- 可输入 **RAG 关键词**控制素材检索方向；
- 点击「**预览上下文与 Token 预算**」，分节查看发给 AI 的内容构成：系统指令 / 风格画像 / 锚点 / 角色卡 / 场景卡 / 卷摘要 / 章摘要 / RAG 素材 / 光标前文，以及每节的 token 数与截断提示。
- 上下文总预算约 6000 token，超出部分按优先级截断。

### 5.6 生成参数（手风琴展开）

- **内容级别**多选：控制检索哪些级别的素材；
- **场景模板**选择：选中含节拍表的模板可「**按节拍生成**」（逐节拍控制剧情节奏）；
- 6 个滑杆：温度 / Top P / Top K / 重复惩罚 / 频率惩罚 / 最大 Token（临时覆盖模型默认值）。

### 5.7 风格参数（手风琴展开）

- **5 维感官权重**：视觉 / 触觉 / 听觉 / 嗅觉 / 心理感受（各默认 20）；
- **5 轴氛围调色板**：轻柔↔粗暴、含蓄↔直白、浪漫↔原始、心理↔动作、慢↔快（-50 ~ +50，默认 0）。

### 5.8 摘要

- 一键生成**章摘要 / 卷摘要 / 全书摘要**；
- 每次保存章节后，后台会**自动生成章摘要**（best-effort，失败不影响写作）；
- 摘要用于长文场景下为 AI 提供前情提要。

### 5.9 历史

生成历史按分支分组保存，可随时**复制、插入光标处、删除**（需确认）。面板底部还可切换当前模型、查看输入/输出 token 统计。

## 6. 素材库

素材库是你的「AI 训练语料 + 资料库」，配合嵌入模型实现 RAG 检索。

### 6.1 导入素材

- 支持格式：**`.txt` 和 `.epub`**（注意：文件选择框里虽然显示了 `.md`，但当前版本实际不支持导入 Markdown，选择 `.md` 会提示"不支持的文件格式"）。
- TXT 导入：自动检测编码（UTF-8 / GB18030），并按「第X章 / Chapter N / 数字、」等模式**自动分章**。
- EPUB 导入：读取标题、作者元数据，按 spine 顺序提取正文。
- 导入前会显示**重复检测预览**，避免重复入库。

### 6.2 素材管理

- **双模式搜索**：语义搜索（依赖嵌入模型）+ 关键词搜索；
- **标签筛选**、新建标签；
- **激活 / 归档**：归档素材不参与检索；
- **编辑**、**插入到光标**、**作为参考发送给 AI**；
- **热冷分层整理**与**清理建议**：帮你甄别低价值素材；
- **批量删除**。

### 6.3 导出素材

支持导出为 **JSON**、**TXT** 或 **EPUB** 电子书，可按标签筛选导出范围。

## 7. 角色 · 场景 · 锚点 · 模板

这些设定会在生成时自动注入上下文，让 AI「记得」你的世界观。

- **角色卡**：角色名、别名、描述、背景、性格特征、人物关系、自定义字段；支持搜索、一键插入角色名到光标、作为参考发送给 AI。
- **场景卡**：场景名、描述、地点、时间、氛围。
- **锚点**：≤50 字的关键设定（如"主角左眉有疤"）+ 分类，是一致性检查的依据（见第 9 节）。
- **场景模板**：可复用的 Prompt 模板，含名称、分类、模板正文，以及可选的**节拍表**（JSON），用于「按节拍生成」。

## 8. 风格画像

让 AI 模仿你（或某位作者）的文风：

1. 在「风格」面板**勾选参考素材** → 点击「**提取画像**」（基于中文分词提取用词与句式特征）；
2. 生成时画像自动注入上下文；
3. 进阶功能：
   - **采纳高分生成后自动校准**：你给生成结果打高分时，画像自动向该结果靠拢；
   - **手动重新校准**；
   - **风格漂移检测**：评估当前文风与画像的偏离程度。

## 9. 一致性检查

每次续写完成后，应用会**自动**用 AI 审查生成文本是否与你的设定矛盾，检查四个维度：

- **锚点**：与设定锚点的冲突；
- **角色**：与角色卡的冲突；
- **场景**：与场景卡的冲突；
- **身体状态**：与章节身体状态快照的冲突（如某角色上一章受伤）。

发现的矛盾以**黄色警告卡片**形式展示在 AI 面板中，供你决定是否修改。

## 10. 隐私与安全

### 10.1 隐私脱敏模式

- 点击顶栏**眼睛图标**一键开关；
- 开启后：编辑器内匹配文本被**遮罩显示**，且**发往 AI 的上下文自动脱敏**；
- 规则完全自定义：名称 + 正则表达式 + 替换文本（默认 `***`），可逐条启停；
- 脱敏只作用于显示层和外发内容，**不会修改你的文稿**。

### 10.2 数据库加密

- 在**设置 → 存储**中启用 **SQLCipher 全库加密**；
- 口令需 ≥6 位，存储在**系统凭据管理器**中；
- 启用或关闭加密均需**重启应用**生效；
- ⚠️ 请牢记口令，遗失将无法打开数据库。

### 10.3 成人模式

- 在**设置 → 隐私**中开关（默认关闭）；
- 开启后解锁：角色卡「身体档案」字段、成人向场景模板、AI 面板的成人内容诊断、内容级别中的成人素材选项。

## 11. 数据存储与备份

### 11.1 数据位置

所有数据保存在本机应用数据目录：

| 平台 | 路径 |
|---|---|
| Windows | `%APPDATA%\com.a.novel-ai-writer\` |
| macOS | `~/Library/Application Support/com.a.novel-ai-writer/` |
| Linux | `~/.local/share/com.a.novel-ai-writer/` |

目录结构：

```
com.a.novel-ai-writer/
├── novel_ai_writer.db          # 主数据库（文稿、素材、设定、配置、向量）
├── backups/
│   └── novel_ai_writer_YYYY-MM-DD.db   # 自动备份
└── logs/                       # 运行日志（按日滚动）
```

- API Key 与数据库口令不在此目录，存于**系统凭据管理器**。

### 11.2 自动备份

- **默认开启**：每天启动时后台自动备份一次（同日重复启动会跳过）；
- 保留策略：默认保留 **7 天**，可选 3 / 7 / 14 / 30 天，超期自动清理；
- 设置 → 存储 中可查看备份列表（日期 + 大小），也可点击「**立即备份**」手动备份。

| **关于** | 版本号、免责声明、检查更新 |

## 14. 常见问题与已知限制

**Q：macOS 提示"无法验证开发者" / "应用已损坏"？**
A：当前版本为 ad-hoc 签名（未公证）。请在访达中**右键 → 打开**；如仍被拦截，可在「系统设置 → 隐私与安全性」中点击"仍要打开"。

**Q：AI 请求报超时错误？**
A：API 请求超过 30 秒无响应会自动超时，并自动重试 2 次（错误信息会注明已重试次数）。频繁超时请检查网络或更换端点。

**Q：为什么导入 `.md` 文件提示"不支持的文件格式"？**
A：当前版本素材导入仅支持 `.txt` 和 `.epub`（文件选择框中显示 `.md` 是已知的前端显示问题）。请先将 Markdown 另存为 `.txt` 再导入。

**Q：AI 没反应 / 报连接错误？**
A：先在**设置 → 模型 / API** 中点「测试连接」。使用 Ollama 时确认本机已运行 `ollama serve` 且已拉取对应模型；状态栏会每 30 秒显示 Ollama 可用状态。

**Q：修改嵌入模型后不生效？**
A：嵌入配置需**重启应用**后生效。

**Q：如何彻底卸载并清空数据？**
A：卸载应用后，手动删除数据目录（见 11.1），并可在系统凭据管理器中删除 `novel-ai-writer` 相关凭据。

**当前版本的已知限制：**

- 无整书导入功能（整书导出支持 Markdown / TXT，素材可单独导出 JSON/TXT/EPUB）；
- 无专注模式（可用顶栏按钮收起左右侧栏获得类似效果）；
- 无代理（proxy）设置项；
- 无 Claude / Gemini 专用提供商（可用 OpenAI 兼容端点接入）；
- 检查更新需手动触发，无启动自动检查。
